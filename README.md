A Simple C Web Server for Fun and Testing.

Status: In Development

WARNING: *ONLY* HOST LOCALLY, ***DO NOT*** USE IN PRODUCTION (MAY CONTAIN SECURITY BUGS).

How to Use (Will update to use make/cmake/docker in future):

Build `server.c`: `gcc server.c -o server`  
Run `server`: `./server "{ text/html file }"`  
Open a browser and go to: *http://localhost:8000/*  
You should see your webpage!  

Version 0.0.0: Initial HTTP Web Server Code.
