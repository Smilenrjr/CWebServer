A Simple C Web Server for Fun and Testing.

Status: In Development

WARNING: *ONLY* HOST LOCALLY, ***DO NOT*** USE IN PRODUCTION (MAY CONTAIN SECURITY BUGS).

How to Use:  

1. `mkdir build`  
2. Put your html file/page (and any other files) into /build subdirectory.  
3. Use `make` (in root/parent directory)
4. Open a browser and go to either: 
	- *http://localhost:8000/*   
	- *http://localhost:8000/{your-html-page}*  

You should see your webpage!  

Version 0.0.0: Initial HTTP Web Server Code.  
Version 0.0.1: Handle other filetypes (i.e. Javascript, etc)
